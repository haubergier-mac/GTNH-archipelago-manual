This is an archipelago implementation for GTNH v2.9, a minecraft modpack that primarly focuses on gregtech alongside a few magic mods.<br>
Do not expect this to take a short amount of time, as this is a massive pack.

The modpack can be downloaded from [GTNH's discord server](https://discord.gg/gtnh)

<h2>Locations:</h2>
quests

If a quest is locked and an appropriate item for it isn't listed here, assume you're missing something or alert me on discord (@haubergier) as there might've been a logic error
